# 人约黄昏 · 资源占位说明

本游戏的视觉素材全部使用 CSS 渐变作为占位背景，**游戏无需图片也可正常游玩**。

## 已实现的可玩流程

1. 封面 → 开场（叙述文字 + 黑衣剪影）
2. 第一章：便利店对话树（名片选择）
3. 第二章：公寓对话树 + 时钟谜题
4. 高潮：教堂对话 + 三选项分支
5. 结局 A/B/C + 隐藏结局 H
6. 存档系统（localStorage 记忆已解锁结局）

## 图片尺寸建议

- 横版场景图：1920 × 1080 或更大
- 剪影立绘：1000 × 1800（高瘦比例）
- 侧脸特写：1200 × 1500
- 文件大小：单张不超过 2MB

## 覆盖后生效机制

CSS 中已经定义：
- 默认使用 CSS 渐变作为背景
- 当 `assets/xxx.jpg` 存在时，浏览器会自动加载（CSS 使用 `background-image: url(...)` 覆盖）

如果你的图片格式是 PNG，把对应代码改成 `.png` 即可。当前代码硬编码 `.jpg`。

## 调试小贴士

打开浏览器控制台（按 F12），可以：

```js
// 跳转到任意场景
__game.switchScene('scene-ending-c')

// 查看当前状态
__game.gameState

// 强制触发结局
__game.triggerEnding('ENDING_A')
```
