## 文件职责

### index.html
- 一个根容器 `#game-container`
- 多个场景 div，通过 JS 切换 `display` 与 `opacity`
- 场景包括：`title-screen` / `chapter1` / `chapter2` / `chapter3` / `ending-a/b/c/hidden` / `credits`
- 顶部进度条 `#progress-bar`（仅作氛围，非强制关卡指示）
- 底部对话框 `#dialog-box`，用于显示叙事文本与选项按钮

### styles.css
- 复古纸张/暖黄灯光配色：`#1a1410`（深木色背景）、`#d4a574`（灯光色）、`#f4e4c1`（文字色）
- 字体：标题用衬线字体（`Georgia, serif`），正文用衬线体，营造书页感
- 场景切换动画：`opacity` 0→1 渐入 + 轻微 `blur` 变化（600ms）
- 浮动文字效果：书中对话用 `@keyframes float-up` 上浮渐显
- 响应式：max-width 800px 居中，移动端可读

### game.js
- 全局状态对象 `gameState = { chapter, choices: [], unlockedEndings: new Set() }`
- 场景渲染函数：`renderChapter1()` / `renderChapter2()` / `renderChapter3()` / `renderEnding(x)`
- 谜题逻辑：
  - **谜题1·拼句子**：3本书各显示一句残句（点击查看），玩家需按顺序点击3本特定位置的书后，按钮"解锁门"才可点击。正确答案存为数组顺序，错误顺序给出"线索不对"的提示。
  - **谜题2·书中对话**：树状结构，对话节点记录 `id, text, options: [{label, next}]`。每次选择都推进 `currentNode`。
- 结局解锁逻辑：localStorage 持久化 `unlockedEndings`，标题页展示已解锁数量
- 隐藏结局触发条件：在第二章所有对话选项中，玩家必须**一次都不重选**（即不点击"重新想想"），且第三章选择结局C"续写"时再额外点一次书中的"空行"才会触发

## 剧情节奏（精简版，5-10分钟）

### 标题屏（15秒）
- 背景：图书馆俯瞰
- 文字逐行浮现："深夜。你是图书馆夜班管理员。""馆长临走前说——""'地下二层有一本书，等了一百年。'""开始值夜"

### 第一章·拼句子（2-3分钟）
- 场景：图书馆一楼书架特写
- 玩家点击书架不同位置，发现3本书各显示一句残句
- 3句拼成完整故事：关于一个在图书馆工作的人"从未说出口的告别"
- 解锁"地下二层"的门

### 第二章·书中对话（3-4分钟）
- 场景：地下二层暗光房间，中央一本空白封皮的书
- 玩家点击书翻页，每页显示对话气泡
- 5轮对话选择，3个选项每轮，影响下一轮对话内容
- 真相浮现：馆长女儿十年前失踪，馆长把她"写"进书里，书的对话就是女孩的回忆

### 第三章·书写结局（1-2分钟）
- 书的最后一页浮现问题："你想写哪一种结局？"
- 三个明确按钮 + 一个隐藏触发条件（见 game.js 说明）

### 结局页（每个30-60秒）
- 结局A·遗忘："有些故事，合上书页就是结局。"
- 结局B·告别："所有的告别，都是为了更好地记住。"
- 结局C·续写："我愿意成为这本书的下一个守夜人。"
- 隐藏结局·重逢："原来她从未离开，只是在等一个愿意读到最后的人。"（指向开发彩蛋）

### 尾声
- "所有的图书馆都是一个人的记忆。"
- 显示解锁进度 + "再读一遍" / "换一种结局" 按钮

## 关键技术细节

- **状态管理**：单一 `gameState` 对象 + `renderScene(sceneId)` 函数切换
- **场景过渡**：CSS `opacity` 过渡，JS `setTimeout(600)` 后切换 DOM
- **文字逐行浮现**：使用 `setInterval` + 字符索引，模拟打字机效果
- **持久化**：`localStorage.setItem('library_endings', JSON.stringify([...]))`
- **图片加载占位**：先用纯 CSS 渐变作为 fallback，图片加载完成后 fadeIn 覆盖
- **音效（可选）**：翻页声用 Web Audio API 合成，避免依赖外部文件
