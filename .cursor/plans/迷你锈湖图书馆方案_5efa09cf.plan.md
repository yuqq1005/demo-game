# 迷你锈湖图书馆：故事与道具方案

> 时代背景：1920–1930 英国，雾中沃斯（Voss）家族私人夜图书馆。风格：Rusty Lake；找物拼真相；主线 + 真结局，无终局三选一。  
> 人物：伊洛恩·沃斯 Elowen Voss；沃斯馆长；沃斯夫人（母亲，本名被彻底抹除）。  
> 判定细则副本：[`条件.md`](条件.md)。

## 完整故事线（制度 + 人情）

### 这座馆是什么

沃斯家族世代继承的私人夜馆，对外面向学者提供夜间阅览。馆内全部登记依靠手写卡片与厚重登记簿，照明使用煤油灯，充斥皮质封皮书、黄铜锁具与泛黄旧纸。 地下藏有家族不对外的铁则：**编目即存在**。录入编目的书、人、记忆，才稳定地「在世界上」。编目之外的文本会搅乱整座馆——无限排列里总有不该被读的组合。

馆长家族代代守护两样事物：

1. **禁区书架**：可以改写读者在编目中的条目。读得太深，你的名字会从「人」变成「待删除」。
2. **《未编目之书》**：厚重皮质封皮的空白古书，是馆的溢流阀。本该暂存「不该进目录的残响、残篇」，等人按规矩读走或等待它自行消散。 家族祖训（地下羊皮手写遗训）：**绝不主动写活人进去**。它收纳的是文本残响，不是活生生的人。

> 「等了一百年」：这本空白古书一直在等候合格的守夜人／读者；馆史上也曾发生过人被错误写入的事件，伊洛恩不是第一个，却是玩家这一夜所能读到的那一个。

### 伊洛恩为什么读禁书

伊洛恩·沃斯，馆长之女，图书馆夜班助手。她并非出于猎奇闯入禁区。 翻阅旧馆档案与卡片登记簿时，她发现母亲几乎已经从馆史里彻底抹除。馆内老雇员只留有模糊印象：“馆长曾经有过一位夫人”，再无其余细节。伊洛恩怀疑母亲也曾落入「待删除」的处境，她想要探明家族守护的秘密，寻找将母亲“读回现实”的办法。

她潜入地下禁区，阅读改写条目的典籍。读得太深之后，编目开始清除她：同事渐渐记不清她的样貌，手写借阅卡上她的名字不断褪色；她时常低烧畏光，身体如同受潮的旧纸张。 她恳求父亲不要对外声张，希望自己扛过去，或是找到把母亲读回来的途径。

### 母亲的真相是什么

沃斯夫人，伊洛恩的母亲。早年协助馆长整理地下禁区藏书，误触碰改写条目的书籍，触发编目的删除机制。 彼时沃斯馆长内心畏惧祖训，不敢动用《未编目之书》。删除流程完整走完，母亲从编目中彻底消失，**连残响都没有进入这本空白古书**。世间仅剩下一个身份标签：“馆长的夫人”。没有名字，没有可供召回的书页，属于不可逆的彻底抹除。

这就是伊洛恩只能在档案中找到一片空白的缘由。 也是后来馆长对女儿做出越界举动的根源：他亲眼见证，**犹豫就会换来人的彻底消散**，于是面对女儿的危机，他走向另一个极端——宁可违背祖训将她写入书中，也不愿再被动等待消亡。

> 母亲不会拥有专属结局。游戏依靠「借阅卡仅存配偶栏」「馆史记录大片空缺」「伊洛恩的内心困境」来暗示这一悲剧。

### 父亲为什么将她写进书中

药物与请假，挡不住来自编目的遗忘。沃斯馆长理解部分规则，但推理自洽却完全错误：

- 编目正在删除伊洛恩（事实正确）
- 《未编目之书》处于编目体系之外（事实正确）
- 将活人的名字写入此书，就可以把她从删除队列挪到暂存，以此救下她（结论错误）

活人一旦被作为条目写进去，便被困在书本容器之中无法自行离开。伊洛恩从未同意这件事。 这是父爱的暴力：他手握家族制度的工具，替女儿决定了她的存在方式。他以为自己弥补了当年对妻子的犹豫，实际上，用另一种形式囚禁了女儿。

**写入仪式，对应三件信物**：用干墨写下伊洛恩全名；以女儿喜爱的野榆干花作为书脊锚点；黄铜蜡封钥匙封锁地下二层入口。 馆长留下手写便签：**不要阅读最后一页**。 他的恐惧来自无知：他只知道写入可以挂起删除，却不知道外人完整阅读可以重编条目。他害怕读完末页，会再次触发删除毁掉女儿，也害怕后人看见自己犯下的罪孽。而事实上，最后一页恰恰是按照规矩将暂存者读回现实的出口。

### 删除令的规则（归来后还会被消吗？）

编目删除分为三态，决定结局逻辑：


| 状态      | 含义                              | 例子                     |
| ------- | ------------------------------- | ---------------------- |
| **待删除** | 已中招，条目正在淡出，但本人依旧存在              | 伊洛恩阅读禁书之后、被写入《未编目之书》之前 |
| **暂存中** | 被移出编目删除队列，冻结在空白书内部；删除令只是挂起，并未取消 | 被写入后的伊洛恩               |
| **已抹除** | 删除流程走完，没有载体留存残响，彻底不可逆消失         | 沃斯夫人（母亲）               |


> 《未编目之书》的正确用法：针对残篇完成完整阅读 → 残响被读走或是自行消散。 馆长错误操作：将活人写入，把「待删除」强行冻结为「暂存中」，删除并未真正取消。

**真结局在做什么：** 玩家找齐全部秘密，即成为伊洛恩的完整见证人。最后一页合格的阅读，不是把她扔回待删除队列，而是启用馆内另一套规则：**以见证重编条目**。旧删除令被覆盖作废，借阅卡上伊洛恩的名字重新清晰。 她归来之后，不会因为过去的旧账自动遭受抹除；但如果她再次深入阅读禁区典籍，会重新触发「待删除」状态。片尾留下冰冷叮嘱：别再打开禁区的书。自由回来了，但她必须带着全部记忆活下去，不存在无限试错的机会。

**主线为什么救不了她：** 你拼凑出真相，却没有完成完整见证。合上书，删除令继续挂起，伊洛恩依旧处于暂存。你读懂了父亲与母亲的悲剧，但还不足以成为可以重编条目的读者。

### 为什么父亲自己不能把女儿读出来（必须是外人）

馆规硬性约束：**写入者 ≠ 读出者**。 《未编目之书》认手：亲手把活人写进去的人，无论怎样阅读，都只算作回看自己写下的笔迹。编目不接受“同手写、同手证”，完成救赎的见证人，必须是完全没有写下这条记录的外来者。 馆长在完成仪式那一刻，就已经剥夺了自己救出女儿的资格。

于是他把钥匙、残页、干花拆开，分散藏在一楼，把守夜工作交付玩家。出口只能交由下一位读者。

两层属于人物的矛盾（锈湖式悲剧）

1. **他惧怕读完最后一页的后果** 便签“不要阅读最后一页”发自真心。祖训只告诫“不可写入活人”，却没有留下“写错之后如何补救”的方法。见过妻子因犹豫消亡，又亲手囚禁女儿，他不敢亲手触碰那最后一页。
2. **他既藏起秘密，又留下窄门** 完成见证需要阅读便签、借阅卡、墨水瓶——这些全部是他最不愿被人看见的罪证。他分散信物，是留下一条获救的可能性；写下警告便签，又是在阻拦这条道路。十年之后再也无法承受，只能将全部矛盾交给今夜的值夜人。

> 澄清：不是让女儿自救。伊洛恩被困书内，既无法离开，也不能读出自己。能够完成见证的，只有作为外来者的玩家。

### 今夜（玩家）

十年过去。外界只流传“馆长的女儿失踪”的传闻。 沃斯馆长将信物散落在一楼，独自离开图书馆，将夜间值守交给你。他作为写入者无法解救女儿，又害怕你误读招致灾难，便留下警告便签。所有矛盾，都交由这一个夜晚。

你巡馆、点灯、开启抽屉，集齐三件信物进入地下，对照书页拼出全部缘由。伊洛恩的剪影只做陈述，不会向玩家做出选择请求。

### 两条收尾（无菜单，无手动抉择）

- **主线结局**：对照完成，点开最后一页，`secretsFound < 4`，页面空白。合上书，天亮。删除令挂起，伊洛恩仍暂存。理解 ≠ 拯救。
- **真结局**：`secretsFound === 4`（便签、借阅卡组、墨水瓶、撕裂相纸）。最后一页浮现全名；剪影到灯下；借阅卡字迹恢复。重编条目，删除令作废。母亲仍无法归来。

> 苦味：救回女儿，救不回母亲。馆长错两次（犹豫 / 乱写）；玩家只完成一半能做的事。

## 核心立意

- **编目即存在**：被目录承认，才能拥有稳定的现世存在。
- **工具被用歪**：溢流阀本用来收纳残篇，却被拿来囚禁活人。
- **爱的暴力**：不尊重当事人意愿的拯救，本质是囚禁。
- **写入者读不出**：亲手写下囚禁的人，不能完成救赎；出口必须交给外人。
- **理解 ≠ 拯救**：主线给予你知识；真结局需要你完成完整的见证。

```

```

可选扩展（有 B1 时）：`floor1 → B1 石阶 → B2`。

1. **一楼大厅（地上，暖黄煤油灯光）**  
   高大橡木书架，黄铜煤油台灯，手写卡片盒，还书推车。主找物区：三件主线信物 + 四件辅助线索。**进入地下／书页内景后不可返回补线。**
2. **地下一层 B1（可选）**  
   潮湿石墙、滴水、远处书页声；无道具、无热点。仅压迫感。省略时设定：早年 B1 坍塌封闭，现存空间仍称「地下二层」，钥匙开门直达 B2，馆长台词不变。
3. **地下二层 B2（书室，禁区核心，冷蓝微光）**  
   中央石台摆《未编目之书》。三信物拖到古书 → 进入书页内景。

> 馆长台词：中文 **「地下二层藏着一本书，它已经等候了一百年。」**  
> *There is a book in the second basement. It has been waiting for a hundred years.*

## 道具与线索设计（迷你锈湖风格）

### 三件主信物（主线必须收集，用于地下古书交互）


| 道具            | 获取位置                    | 叙事含义                                                                       | 用法                                        |
| ------------- | ----------------------- | -------------------------------------------------------------------------- | ----------------------------------------- |
| **黄铜蜡封钥匙**    | 值班桌抽屉，必须先点亮黄铜煤油台灯才能打开抽屉 | 馆长封存地下入口的私钥，带有家族蜡印                                                         | 打开一楼包铁地下室大门，通往地下通道                        |
| **批注残页**      | 皮质藏书《图书馆管理学》的书页夹缝       | 手写笔记：*She is not lost. She has been written into the book.*（她并非失踪，她被写进了书里） | 拖拽到古书，对应插图【鹅毛笔】，解锁片段：伊洛恩陷入待删除，馆长以干墨写下她的名字 |
| **干花书签（野榆花）** | 遗忘还书推车                  | 伊洛恩生前喜爱的野花，仪式的书脊锚点                                                         | 放置古书书脊缺口，唤醒书页，显现伊洛恩剪影                     |


### 辅助线索物（解锁真结局必须全部阅读；点击即记录，不需要拾取）

全部在一楼（可分散在抽屉、卡片盒、桌面）。点击弹出特写即计入 `secretsFound`；「看见即见证」；不挡主线。

| 道具 | 计入秘密？ | 作用 |
|------|-----------|------|
| 熄灭的黄铜煤油灯 | **否**（门控） | 点亮后抽屉才可交互 |
| 馆长手写便签 | 是 → +1 | *Do not read the final page.* / 不要阅读最后一页 |
| 手写借阅卡片组（两张） | 是 → +1（整组） | 伊洛恩卡：失踪日停更、名字褪色；夫人卡：姓名空白、配偶栏仅 Voss |
| 干涸鹅毛笔墨水瓶 | 是 → +1 | 写入活人的仪式物证 |
| 撕裂银盐旧相纸 | 是 → +1 | 女人面部撕毁，仅余衣裙一角；母亲被抹除的无字伤痕 |
| 空行书页特写 | 否（结局演出） | 真结局浮现伊洛恩全名；主线保持空白 |

`secretsFound === 4` 才开真结局。详见 [`条件.md`](条件.md)。


### 真相拼图（书页内三步对照）

玩家把三件信物拖入书页插槽，分段解锁真相：

1. **钥匙 → 插图【门】** → 地下入口来自那场违训仪式；家族祖训严禁将活人写入《未编目之书》。
2. **批注残页 → 插图【鹅毛笔】** → 伊洛恩阅读禁书之后开始被世界遗忘；馆长用干墨，将她的名字写进空白古书。
3. **干花书签 → 插图【少女剪影】** → 伊洛恩显现，台词：*He thought he was saving me. Yet I simply… cannot get out.* / 中文：**“他以为自己是在救我。可我只是……再也走不出去。”**

> 辅助线索回收逻辑：褪色借阅卡、干涸墨水瓶、警告便签、撕裂照片，共同强化「抹除‑封存‑见证出口」整套主题。

## 结局设计：不做终局手动选项

锈湖式设计：结局差异来源于**探索深度**，而不是结局界面的道德选择按钮。

### 两条路径


| 路径              | 触发条件                                        | 发生内容                                                                                                                                   |
| --------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **主线结局·书页之中的人** | 集齐三件主线信物完成书页对照，**没有读完全部辅助线索**               | 听完伊洛恩全部独白，书本合上。天亮，图书馆归于寂静。玩家知晓悲剧真相，但是没有完成完整见证。删除令依旧挂起，伊洛恩困于书内。 片尾：**有些人并未离去，只是被写进了一本本不该被书写的书里。**                                       |
| **真结局·被读出来**    | 集齐三件主线信物，**并且阅读全部辅助线索（便签、两张借阅卡、墨水瓶、撕裂旧相纸）** | 点击最后一页，空白行浮现伊洛恩全名。剪影走出书页来到灯下；伊洛恩的借阅卡字迹重新恢复清晰。完成外人的完整见证，旧删除令作废。伊洛恩回到现实。母亲依旧彻底消失，没有任何残响可供召回。 片尾：**这一夜，终于有人读到了最后一页。** 追加冷的告诫：永远不要翻开禁区的藏书。 |
